# Development Guidelines

This directory contains all development guidelines, design documents, and coding standards for the Riverrun project.

## Contents

### UI/UX Guidelines (`ui-direction/`)

- `about.md` - Project overview and design philosophy
- `color-guidelines.md` - Color palette and usage guidelines
- `components.md` - Component design patterns
- `themes.md` - Theme system documentation
- `trading-patterns.md` - Trading UI patterns and best practices
- `typography.md` - Typography guidelines

### Coding Standards

- `coding-style.md` - Code style conventions and best practices
  - TypeScript type conventions (prefer `undefined` over `null`)
  - Code organization and structure
  - Naming conventions

## Purpose

These guidelines ensure consistency across the codebase and help new developers understand:

- How to structure code
- What design patterns to follow
- How to implement UI components
- What coding standards to adhere to

## Contributing

When making changes to these guidelines:

1. Discuss significant changes with the team first
2. Keep guidelines practical and actionable
3. Include examples where appropriate
4. Update this README if adding new guideline documents
